/*========================================
Map Drop Nerf System – README (GM Guide)
========================================

ระบบนี้ใช้สำหรับ “ปรับลด/เพิ่มอัตราดรอปไอเท็มรายแมพ แบบเรียลไทม์”
โดยทีมงานหน้าบ้านสามารถสั่งงานได้เองผ่านคำสั่ง GM
ไม่ต้องรอ Dev และไม่กระทบคำสั่ง @mi

----------------------------------------
หลักการทำงาน
----------------------------------------
- ปรับเฉพาะตอน “สุ่มดรอปจริง” ตอนมอนตาย
- ไม่เปลี่ยนเรทที่แสดงใน @mi
- แยกปรับได้ตามประเภทไอเท็ม:
  ETC / equip / Weapon / card / all

ค่าที่ใช้เป็น “ตัวคูณเปอร์เซ็นต์”
100 = ปกติ
90  = เหลือ 90% (เนิฟ 10%)
50  = เหลือครึ่งเดียว
0   = ไม่ดรอปเลย

----------------------------------------
ประเภทไอเท็ม (Type)
----------------------------------------
ETC    = ของทั่วไป วัตถุดิบ ขยะ ของเควส
equip  = อุปกรณ์/เกราะ (ไม่รวมอาวุธ)
Weapon = อาวุธ
card   = การ์ด
all    = ทุกประเภทพร้อมกัน

พิมพ์ได้ทั้งตัวเล็ก/ใหญ่

----------------------------------------
คำสั่งหลัก
----------------------------------------

@nerf <map> <type> <delta>
ปรับเพิ่ม/ลด จากค่าปัจจุบัน

@nerfset <map> <type> <value>
ตั้งค่าเป็นตัวเลขตายตัว

@nerfclear <map> [type]
ล้างค่าเนิฟ กลับเป็น 100%

@nerflist
แสดงรายชื่อแมพที่กำลังถูกเนิฟ

----------------------------------------
ตัวอย่างการใช้งานจริง
----------------------------------------

ลดดรอปการ์ดในแมพ 10%
@nerf moc_fild06 card -10

ลดดรอปอาวุธ 20%
@nerf moc_fild06 Weapon -20

ลดดรอปอุปกรณ์ 15%
@nerf moc_fild06 equip -15

ลดของทุกประเภทในแมพ 10%
@nerf moc_fild06 all -10

ตั้งค่าการ์ดให้เหลือ 50% แบบตายตัว
@nerfset moc_fild06 card 50

ตั้งอาวุธเหลือ 80%
@nerfset moc_fild06 Weapon 80


ล้างค่าเนิฟทั้งแมพ
@nerfclear moc_fild06

ล้างเฉพาะการ์ด
@nerfclear moc_fild06 card

ดูว่าแมพไหนโดนเนิฟอยู่
@nerflist

----------------------------------------
แนวทางใช้งานแนะนำ
----------------------------------------

กรณีคนฟาร์มการ์ดหนัก:
@nerf <map> card -10 ถึง -30

กรณีของสวมใส่ล้นตลาด:
@nerf <map> equip -20
@nerf <map> Weapon -20

จบกิจกรรม  คืนค่าปกติ:
@nerfclear <map>

----------------------------------------
ข้อควรระวัง
----------------------------------------

- ค่าจะถูกจำกัดช่วง 0 – 200
- ถ้าลดจนเหลือ 0 = ไม่ดรอปเลย
- รี map-server แล้วค่าอาจรีเซ็ต
- แนะนำให้ใช้ @nerflist ตรวจสอบทุกครั้งหลังสั่ง

----------------------------------------
จบคู่มือ
----------------------------------------
========================================*/
